## 📌 Sobre o projeto

O **CodeQuiz** é um projeto acadêmico desenvolvido com **PHP, HTML e CSS**, com o objetivo de aplicar conhecimentos de desenvolvimento web na criação de uma plataforma educacional.

A proposta é reunir conteúdos, exemplos e exercícios em um único ambiente, proporcionando uma experiência simples, intuitiva e acessível para quem deseja aprender programação.

## ✨ Funcionalidades

- 📚 **Módulos de aprendizagem:** conteúdos de HTML, CSS, JavaScript, PHP e Python.
- 📖 **Documentação:** conceitos fundamentais, exemplos práticos e boas práticas.
- 🧠 **Quizzes:** exercícios para testar conhecimentos.
- 💻 **Editor de código:** ambiente para praticar programação.
- 📈 **Área pessoal:** espaço voltado ao acompanhamento da evolução nos estudos.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| PHP | Processamento no servidor e funcionalidades dinâmicas |
| HTML5 | Estrutura das páginas |
| CSS3 | Estilização e identidade visual |

## 🎨 Interface

O projeto possui uma interface minimalista, com tons de azul, branco e ciano. O layout prioriza a legibilidade, a organização dos conteúdos e uma navegação intuitiva.

## 🎯 Objetivo acadêmico

Aplicar os conhecimentos adquiridos em desenvolvimento web, praticando a integração entre PHP, HTML e CSS e desenvolvendo uma aplicação com estrutura organizada e identidade visual própria.
